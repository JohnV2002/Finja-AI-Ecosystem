# Version scheme

```
MAJOR . FEATURES . BUGS
```

| Part | Bump when |
|------|-----------|
| MAJOR | Breaking API / identity change |
| FEATURES | New feature(s), backward compatible enough to stay same major |
| BUGS | Fixes only |

All files in the **same module directory** must show the **same** `Version: X.Y.Z`.  
`New in vX.Y.Z:` bullets are **per file**.
